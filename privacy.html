Privacy information

Updated November 2, 2026

This website

This is a static information website for NeverLose, maintained by the developer using the handle iamphos. It has no sign-in, forms, analytics scripts, advertising, or application cookies. Fonts and styles are served with the site.

This website is hosted with GitHub Pages. GitHub logs visitor IP addresses for security purposes, including visits from people who are not signed in. See GitHub Pages data collection and the GitHub Privacy Statement for details.

The desktop prototype

Settings, champion pool selections, draft state, and aggregate statistics are handled locally on the user's device. The app does not include developer-operated telemetry or an account service.

A Riot API key is stored in a local TXT file. The key is sent to Riot with authenticated match-data requests and is not submitted to this website. Local League client credentials are used only for local client access.

Riot match-data collection temporarily processes player identifiers to retrieve games. Saved statistical datasets contain aggregate counts and match IDs rather than player identifiers. Manually imported files and exports remain under the user's control.

External services

The desktop app contacts Riot's APIs for match and ranking data, and Data Dragon for champion metadata and images. These requests are subject to the providers' practices. The website contains outbound links; following one sends a request to that destination.

Contact

For questions about this project, use the contact options on the developer's GitHub profile. Do not send API keys or client credentials.
